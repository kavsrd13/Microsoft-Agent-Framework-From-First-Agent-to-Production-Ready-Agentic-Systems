# Sessions

Creates one `AgentSession` and reuses it for two runs, allowing the second turn to include the first turn's conversation history.

Source: [Session](https://learn.microsoft.com/en-us/agent-framework/agents/conversations/session), [official multi-turn sample](https://github.com/microsoft/agent-framework/blob/main/python/samples/01-get-started/03_multi_turn.py).
