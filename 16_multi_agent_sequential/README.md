# Sequential multi-agent orchestration

Runs a writer and then a reviewer. The shared conversation passes through both participants, and both visible responses are returned.

Source: [Sequential orchestration](https://learn.microsoft.com/en-us/agent-framework/workflows/orchestrations/sequential), [official sample](https://github.com/microsoft/agent-framework/blob/main/python/samples/03-workflows/orchestrations/sequential_agents.py).
