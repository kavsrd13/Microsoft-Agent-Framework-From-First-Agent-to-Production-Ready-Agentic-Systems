# MCP tool

Opens a client-managed Streamable HTTP connection to the Microsoft Learn MCP endpoint and exposes its tools to the Foundry-backed agent for one run.

The endpoint is public but the demo still requires outbound network access. Change `MCP_URL` to use another trusted MCP server.

Source: [Using local MCP tools](https://learn.microsoft.com/en-us/agent-framework/agents/tools/local-mcp-tools), [official Foundry MCP sample](https://github.com/microsoft/agent-framework/blob/main/python/samples/02-agents/providers/foundry/foundry_chat_client_with_local_mcp.py).
