# Function tools

Defines a typed function with `@tool`, adds it to the agent, and lets the Foundry model decide when to call it. `never_require` is used only because this read-only classroom tool has no side effects.

Source: [Tools overview](https://learn.microsoft.com/en-us/agent-framework/agents/tools/), [official add-tools sample](https://github.com/microsoft/agent-framework/blob/main/python/samples/01-get-started/02_add_tools.py).
