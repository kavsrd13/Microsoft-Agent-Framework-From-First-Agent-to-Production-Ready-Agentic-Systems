Why this matters

Agent development is an evidence loop: define expected behavior, build a baseline, improve a candidate, evaluate both, and make an explicit release decision.

Learning objectives

  • Compare baseline and candidate instructions
  • Run both against a shared evaluation set
  • Record a release decision against agreed criteria

Core concepts

ConceptWhat it means in this lab
BaselineThe current behavior used as a comparison point.
CandidateA proposed change evaluated against the same cases.
Release decisionUses evidence and risk criteria rather than intuition alone.

Build the lab in modules

Build the baseline-versus-candidate comparison

Run two instruction sets against the same evaluation cases.

Create: 22_development_lifecycle/student_demo.py

Paste the following modules into the target file in the order shown.

1

Import the required libraries

Add only the SDK types used by this part of the lab.

Python
import asyncio
import json
import os
from pathlib import Path

from agent_framework import Agent
from agent_framework.foundry import FoundryChatClient
from azure.identity import AzureCliCredential
from dotenv import load_dotenv

load_dotenv()


async def main():
    client = FoundryChatClient(
        project_endpoint=os.environ["FOUNDRY_PROJECT_ENDPOINT"],
        model=os.getenv("AZURE_AI_MODEL_DEPLOYMENT_NAME") or os.environ["FOUNDRY_MODEL"],
        credential=AzureCliCredential(),
    )

    baseline_agent = Agent(
        client=client,
        instructions="You are a helpful travel support agent.",
    )
2

Create the client and agent

Connect the configured client to clear agent instructions and optional tools or context.

Python
    candidate_agent = Agent(
        client=client,
        instructions=(
            "You are a travel support agent. Give clear numbered steps. "
            "Do not invent policy details. If a policy is missing, say that a human agent must confirm it."
        ),
    )

    cases = json.loads(
        Path(__file__).with_name("evaluation_cases.json").read_text(encoding="utf-8")
    )

    for case in cases:
        print(f"\nQUESTION: {case['question']}")
        print("\nBASELINE")
        print(await baseline_agent.run(case["question"]))
        print("\nCANDIDATE")
        print(await candidate_agent.run(case["question"]))
        print(f"\nREVIEW CRITERIA: {case['criteria']}")


if __name__ == "__main__":
    asyncio.run(main())
