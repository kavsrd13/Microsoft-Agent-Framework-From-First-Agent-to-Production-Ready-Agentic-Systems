# Concurrent multi-agent orchestration

Fans one prompt out to three specialists in parallel and uses the default aggregator to fan their messages back into one `AgentResponse`.

Source: [Concurrent orchestration](https://learn.microsoft.com/en-us/agent-framework/workflows/orchestrations/concurrent), [official sample](https://github.com/microsoft/agent-framework/blob/main/python/samples/03-workflows/orchestrations/concurrent_agents.py).
