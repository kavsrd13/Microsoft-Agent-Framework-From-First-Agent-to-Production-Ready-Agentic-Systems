# Middleware

Shows two class-based middleware scopes: agent middleware can stop a run and replace its result, while function middleware wraps a tool invocation to measure duration.

Source: [Agent middleware](https://learn.microsoft.com/en-us/agent-framework/agents/middleware/), [official class-based sample](https://github.com/microsoft/agent-framework/blob/main/python/samples/02-agents/middleware/class_based_middleware.py).
