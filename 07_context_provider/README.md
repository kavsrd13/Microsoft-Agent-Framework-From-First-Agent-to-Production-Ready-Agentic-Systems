# Context provider

Implements `before_run` and `after_run`. It extracts a user's name into provider-owned session state and injects personalized instructions into the next model call.

Source: [Adding context providers](https://learn.microsoft.com/en-us/agent-framework/journey/adding-context-providers), [Get Started: memory](https://learn.microsoft.com/en-us/agent-framework/get-started/memory).
