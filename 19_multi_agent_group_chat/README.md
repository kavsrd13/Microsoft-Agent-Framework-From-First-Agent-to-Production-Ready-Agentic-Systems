# Group-chat multi-agent orchestration

Uses a deterministic round-robin selector to let an expert, verifier, and clarifier collaborate in a shared transcript for a bounded number of messages.

Source: [Workflow orchestration patterns](https://learn.microsoft.com/en-us/agent-framework/workflows/orchestrations/), [official group-chat selector sample](https://github.com/microsoft/agent-framework/blob/main/python/samples/03-workflows/orchestrations/group_chat_simple_selector.py).
