# Evaluation

Runs the live Foundry-backed agent against two queries, then applies one built-in keyword check and one custom local evaluator. Uncomment a `raise_for_status()` assertion when adapting it for CI.

Source: [Agent evaluation](https://learn.microsoft.com/en-us/agent-framework/agents/evaluation), [official local evaluation sample](https://github.com/microsoft/agent-framework/blob/main/python/samples/02-agents/evaluation/evaluate_agent.py).
