# Tool approval

Marks a side-effecting calendar tool with `approval_mode="always_require"`. The agent pauses, the program shows the proposed call, and the user approves or rejects it before execution.

Source: [Function tools with human approval](https://learn.microsoft.com/en-us/agent-framework/agents/tools/tool-approval), [official session-based approval sample](https://github.com/microsoft/agent-framework/blob/main/python/samples/02-agents/tools/function_tool_with_approval_and_sessions.py).
