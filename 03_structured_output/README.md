# Structured output

Passes a Pydantic model through `options={"response_format": CityInfo}` and reads the parsed value from `result.value`.

Source: [Producing structured outputs with agents](https://learn.microsoft.com/en-us/agent-framework/agents/structured-outputs), [official Python sample](https://github.com/microsoft/agent-framework/blob/main/python/samples/02-agents/providers/openai/client_with_structured_output.py).
